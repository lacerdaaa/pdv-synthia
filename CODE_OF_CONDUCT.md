# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: queremos uma comunidade acolhedora para qualquer pessoa, independentemente de experiência, origem,
identidade ou aparência. Seja gentil, aceite críticas construtivas, foque no que é melhor para o projeto e para
quem usa o sistema no balcão. Assédio, ofensas e ataques pessoais não são tolerados em issues, PRs, discussões
ou qualquer outro espaço do projeto.

Para relatar um comportamento inadequado, fale em particular com o mantenedor pelo GitHub
([@lacerdaaa](https://github.com/lacerdaaa)). Todo relato é tratado com sigilo, e o mantenedor pode remover
conteúdo ou bloquear participantes que descumprirem este código.
